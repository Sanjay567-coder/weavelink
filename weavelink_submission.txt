2. EVALUATOR QUCK-START GUIDE (THE HACKATHON DEMO BAR)
------------------------------------------------------------------------
To make reviewing each screen and user role simple, we have built a custom
floating Developer Hackathon Panel directly into the application.

👉 Look for the floating "Indigo Console/Terminal" icon ( >_ ) on the 
   bottom-left corner of any screen.

Click it to expand the panel and access the following functions:

- ROLE SWITCHER: Log in instantly with one click as Admin, Weaver, or 
  Treasurer. The app handles Phone OTP Authentication automatically in the 
  background, switching database roles and permissions on the fly.
  
- SCREEN JUMP: Skip directly to any of the 8 screens to inspect the user 
  interfaces and workflows:
  - Screen 1: Order Details received (Admin review)
  - Screen 2: Share to coop group chat
  - Screen 3: Live cooperative chat room (Weaver voting & consensus)
  - Screen 4: Real-time consensus check SVG donut chart
  - Screen 5: Workforce allocation using a proportional suggest algorithm
  - Screen 6: Loom station production tracking dashboard
  - Screen 7: Wage payout splits ledger (Mark-as-Paid transfers)
  - Screen 8: Regional yarn price-benchmarking graphs & cooperative pooling map
